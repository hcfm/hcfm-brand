  3. Open your signature settings, paste, set as default for new messages and replies, save:
    • Outlook Classic (Windows): File → Options → Mail → Signatures
    • New Outlook (Windows): Settings (gear) → Accounts → Signatures
    • Outlook for Mac: Outlook menu → Settings → Signatures
    • Outlook on the web: Settings (gear) → Account → Signatures → Add signature. Then tick Set default for new messages and Set default for replies and forwards before you save, or it will not go out on anything.
