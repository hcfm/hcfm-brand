HCFM Signature Installer

One-click install of the new email signature, no copy-paste needed.

1. Tell us who you are

Three personal fields. The org name, address, website, and banner are filled in automatically based on which ministry you pick.

2. Drag this button to your bookmarks bar

This button holds a one-click installer personalized just for you. Drag it up to your browser's bookmarks bar so you can click it later.

Install HCFM Signature

Don't see your bookmarks bar? In Chrome / Edge, press Cmd+Shift+B (Mac) or Ctrl+Shift+B (Windows).

3. Use it on your Outlook signature

  1. Open outlook.office.com (Outlook on the Web).
  2. Click the gear icon in the top right, then Mail, then Signatures.
  3. Either create a + New signature or click the pencil icon to edit your existing one.
  4. Once the signature editor is open and visible, click the bookmark you just saved from your bookmarks bar.
  5. The signature will appear in the editor automatically, properly formatted.
  6. Make sure Set default for new messages and Set default for replies and forwards are checked, then click Save.
Why this works: Outlook's normal copy-paste process strips some formatting (which is why every previous test showed weird gaps). The bookmark installs the signature directly into Outlook's editor, bypassing the paste filter, so you get the exact pixel-perfect signature.
If clicking the bookmark shows an error about not finding the editor: you didn't open the signature edit dialog yet. Go to Settings → Mail → Signatures, click the pencil to edit a signature so the editor appears, THEN click the bookmark.
